Project Title: Car Counter on Highway (Using OpenCV)

We’ll simulate counting cars using a video or webcam. We’ll use:
OpenCV: to process video and detect movement
cv2.createBackgroundSubtractorMOG2(): to detect moving cars

First, install OpenCV:
pip install opencv-python

Project Files

A Python file: car_counter.py (if using normal Python software)
